# Source and distribution boundaries

This is a source-only research snapshot of a Raspberry Pi 5 port. External
Aluminium/Google system images, apps and firmware are not included in Git. OS
snapshot Release assets include their original components and notices. Upstream
AOSP, Linux, Mesa, Raspberry Vanilla, KonstaKANG and host tools retain their
respective licenses and notices; obtain upstream source trees separately.
References, hashes and Android resource/package identifiers describe compatibility
work and do not grant rights to the referenced external software.

The destination repository's existing MIT license is retained in LICENSE.
It covers project-authored material; external components retain their own
licenses and notices. Referencing an external artifact does not relicense it.
Existing notices in source files are retained.
